# Security Policy

## Supported Versions

Security updates are provided for the latest releases on the `main` branch.

| Version | Supported |
| :--- | :--- |
| `main` / latest | :white_check_mark: Active |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential risk in **AgentEverywhereFlow-WebUI**, please **do not** file a public issue.

Please report vulnerabilities privately via:
1. **GitHub Private Vulnerability Reporting**: Go to **Security** -> **Advisories** -> **Report a vulnerability**.
2. **Email**: Contact the maintainer directly at `mcocdaa` / `2021137961@qq.com`.

### Please include:
- Description of the issue (e.g. XSS, WebSocket hijacking, unauthorized local command execution).
- Steps to reproduce.
- Affected browser and operating system.
- Proposed patch or workaround if available.

### Response Commitment:
- Initial response within **48 hours**.
- Fixes verified in private branch before public release.
